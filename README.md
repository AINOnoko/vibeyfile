# vibeyfile 🌌

Минималистичный консольный файловый менеджер (TUI) с вкладками для навигации по директориям и открытых текстовых файлов. Проект написан на чистом Си с использованием библиотеки `ncurses` и ориентирован на Unix-подобные системы.

> **Важное примечание:** По факту данный проект — это чистый **вайбкод**. Он создавался для души, ради эстетики старой школы (Midnight Commander/Far Manager) и удовольствия от написания легковесного софта без лишних GUI-нагромождений. Код написан лаконично, работает быстро и выполняет свои задачи на все 100%.

## ✨ Особенности

- **⚡ Истинный минимализм:** Приятная сине-серая палитра и интерфейс, который не отвлекает от работы.
- **👁️ Интегрированный предпросмотр:** Мгновенный просмотр содержимого текстовых файлов и исходного кода в соседней панели (включается по клавише `v`).
- **🗂️ Система вкладок:** Независимые табы (`1..4`) для быстрой навигации по каталогам и полноценные вкладки для открытых текстовых файлов внутри менеджера.
- **🏷️ Кастомные маркеры:** Буквенные индикаторы типов файлов прямо в списке: `[C]` — исходный код, `[Z]` — архивы, `[X]` — исполняемые файлы, `[<]` — родительская директория.
- **📦 Встроенный функционал:** Быстрое создание папок/файлов, генерация из шаблонов (C, Python, Bash), встроенная архивация (`.zip`, `.tar.gz`, `.tar.xz`) и удобное меню «Избранное» (Закладки).
- **🖱️ Нативная поддержка мыши:** Клик для выбора, двойной клик для открытия директорий и скролл колесиком.

## 🛠️ Зависимости

Для сборки необходима библиотека **ncurses** с поддержкой Unicode (`ncursesw` для корректной работы с кириллицей). 

На Debian/Ubuntu-подобных дистрибутивах:
```bash
sudo apt install libncursesw5-dev
```

## 🚀 Компиляция и сборка

Проект комплектуется гибким и строгим `Makefile`, поддерживающим несколько режимов сборки с жесткими флагами компилятора (`-Wall -Wextra -Werror` и др.).

### 1. Стандартная сборка (Release)
Оптимизированный бинарник без отладочной информации (`-O2`):
```bash
make
```
*Альтернативная команда:* `make release`. Запуск исполняемого файла выполняется через `./fm` (или командой `make run`).

### 2. Отладочная сборка (Debug)
Сборка без оптимизаций, со всеми отладочными символами и активными макросами отладки:
```bash
make debug
```
Создает исполняемый файл `fm-debug`.

### 3. Сборка с санитайзерами
Компиляция с инструментами статического анализа Address, Undefined Behavior и Leak Sanitizer для отслеживания ошибок работы с памятью:
```bash
make sanitize
```
Создает исполняемый файл `fm-asan`.

### 4. Проверка на утечки памяти (Valgrind)
Автоматический запуск утилиты `valgrind` с глубоким анализом распределения памяти на дебаг-бинарнике:
```bash
make valgrind
```

### 5. Полный цикл проверок
Очистить прошлые сборки, скомпилировать все режимы и прогнать тесты памяти:
```bash
make check
```

### 6. Очистка артефактов сборки
Удаление всех скомпилированных исполняемых файлов и директорий с отладочной информацией:
```bash
make clean
```

Для вывода полной встроенной справки по доступным целям сборки используйте команду `make help`.

## ⌨️ Управление (Горячие клавиши)

| Хоткей | Действие |
| :--- | :--- |
| `j` / `↓` | Курсор вниз |
| `k` / `↑` | Курсор вверх |
| `l` / `→` / `Enter` | Войти в каталог / Открыть файл |
| `h` / `←` / `Backspace` | Перейти на уровень вверх |
| `Space` | Выделить файл / снять выделение |
| `Tab` | Переключить активную панель (в режиме сплита) |
| `m` | Включить/выключить двухпанельный режим (Split) |
| `v` | Включить/выключить панель предпросмотра |
| `a` | Открыть главное контекстное меню действий |
| `/` | Поиск файлов по имени «на лету» |
| `p` | Открыть меню «Избранное» (Закладки) |
| `s` / `S` | Изменить поле сортировки / Реверс сортировки |
| `F1` .. `F4` | Быстрое переключение между четырьмя вкладками |
| `r` | Обновить содержимое текущей директории |
| `i` | Показать встроенное окно справки |
| `q` | Выход из приложения |
